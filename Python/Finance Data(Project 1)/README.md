# 📊 Financial Data Analysis – Investor Investment Preferences

## 📌 Project Overview

This project explores financial survey data to analyze investor demographics, investment preferences, and the relationship between different investment avenues. Using Python and data visualization techniques, the analysis identifies patterns in investor behavior and compares preferences across various financial assets.

The project demonstrates practical skills in **Data Analysis, Exploratory Data Analysis (EDA), Data Visualization, and Statistical Analysis**.

## 🎯 Project Objectives

- Analyze investor demographics, including age and gender.
- Examine preferences across different investment avenues.
- Compare investment preferences by gender.
- Calculate average investor age by investment avenue.
- Analyze correlations between financial asset preference scores.
- Visualize investment preference rankings and distributions.
- Generate insights from survey data to better understand investor behavior.

## 🛠️ Technologies Used

- **Python** – Data analysis and programming
- **Pandas** – Data manipulation and analysis
- **NumPy** – Numerical operations
- **Matplotlib** – Data visualization
- **Seaborn** – Statistical visualization
- **Jupyter Notebook** – Interactive analysis and documentation
